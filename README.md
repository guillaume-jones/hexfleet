# HexFleet

Hexagon-tile based game with simultaneous turns and unique rules.
Supports singleplayer and online multiplayer with a leaderboard.

Built with Tailwind + React + Next.js.

## Development

1. Run `npm i` to fetch all packages.
2. Run `npm run dev` to start the local server. Default port is 3000.

## Deployment

To deploy Firebase functions, run `npm run deploy-firebase` and login via web browser.

To deploy the website, push a commit to the `production` branch, which is linked to
AWS Amplify auto-deployment on the AWS account guillaume.jones.mint@gmail.com.
