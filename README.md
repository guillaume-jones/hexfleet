# HexFleet

Hexagon-tile based game with simultaneous turns.
Supports singleplay and online multiplayer.

## Installation

1. Run `npm i`

## Usage

To start the local server: `npm run dev`

Then navigate to [http://localhost:3000](http://localhost:3000) in browser to see the web app.

## Deployment

To deploy Firebase functions, run `npm run deploy-firebase` and login via web browser.

To deploy the website, push a commit to the `production` branch, which is linked to
AWS Amplify auto-deployment on the AWS account guillaume.jones.mint@gmail.com.
